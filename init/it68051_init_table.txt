# IT68051 I2C initialisation table  (FPGA I2C master replay)
#
# Source : ITE68051_MEGAWIN_EVB_1.57.20200928/src/iTE6805_INI_Table.h
#          (active, non-commented entries; macros resolved from config.h)
#          + post-table fixed sequence extracted from iTE6805_DRV.c
#          (iTE6805_Init_fsm / iTE6805_Init_CAOF / iTE6805_Set_Video_Tristate
#           / iTE6805_Set_TTL_Video_Path / iTE6805_Port_Select_Body) and
#          iTE6805_SYS.c (iTE6805_Enable_Video_Output).
#
# Semantics  (firmware hdmirxset() is read-modify-write!)
#   WRITE  bank,reg,mask,val : reg <= (reg & ~mask) | val ;  mask=0xFF -> plain write
#   WRITEF bank,reg,00,val   : reg <= val                       (firmware hdmirxwr)
#   DELAY ms
#   POLL  bank,reg,mask,val  : wait (reg&mask)==val, FPGA timeout=250ms then continue
#   END
#
# Device I2C address: 8-bit write 0x90 / read 0x91 (7-bit 0x48),
#   same as the ITE EVB firmware (config.h ADDR_HDMI=0x90).
#   !! PCADR(U5.23) is pulled LOW on this board: R8 (0R pull-up to
#   !! OVDD33) is DNP / not populated (user-confirmed decision), so only
#   !! R6 (10k to GND) sets the level -> address 0x90 per IT68051
#   !! datasheet Table 4-3.  (The V1.4 netlist still lists R8 as a
#   !! footprint placeholder - it is not soldered.)
#
# Output mode chosen by the resolved table: eTTL_SepSync_FullBusDDR_BYPASS_CSC
#   - QD[59:0] dual-pixel DDR, separate HSYNC/VSYNC/DE, CSC bypass (RGB passthrough)
#   - YUV422 is NOT produced by the chip in v1; the FPGA converts RGB->YUV422.
#   - Dual-pixel DDR requires HTotal%%4==0 (IT68051 datasheet note, Table 5-1).
#
# Not replayed by FPGA v1 (see docs/README.md 'not verified' list):
#   OCLK_Cal dynamic measurement (static 0x91/0x92 approximation used),
#   EDID RAM write (EVB EDID caps TMDS at 300MHz -> cannot advertise 2K144),
#   MHL table, HDCP repeater, CEC runtime init, runtime INT# polling FSM.
#
